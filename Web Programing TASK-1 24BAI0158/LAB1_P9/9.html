Adding Images to a Web Page

This page demonstrates different ways to add images in HTML.

1. Image from an External Website (URL)

2. Image from Local Computer

To display an image from your local computer, the image file must be saved on your system and the correct file path should be provided.

3. Image from Project Folder

When the image is stored inside the project folder, only the image name or relative path is required.
